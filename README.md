# Pokémon Memory

A fun, interactive memory card game featuring Pokémon! Flip cards to find matching pairs before time runs out. Players can select a Pokémon generation, and the cards shuffle randomly every game.

## Features

- 12 cards (6 pairs) per game.
- Choose Pokémon generation (Gen 1-9).
- Timer countdown of 30 seconds.
- Cards flip back after 1 second if not a match.
- Responsive design for desktop and mobile.
- Smooth card flip animations and hover effects.
- Modal shows victory or defeat with option to play again.
- Shuffle Pokémon and card positions every new game.
- Rules displayed before starting.

## How to Play

1. Open the game in a browser.
2. Select the Pokémon generation you want to play with.
3. Read the rules in the box.
4. Click **Start Game**.
5. Click on two cards to flip them:
   - If they match, they stay face up.
   - If they do not match, they flip back after 1 second.
6. Find all 6 pairs before the 30-second timer runs out.
7. Win to see the victory modal, or try again if time runs out.
